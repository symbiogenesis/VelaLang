VelaLang · Designed alongside VerifiedOS

Systems control and machine-checked mathematics in one explicit surface.

Vela combines call-site-visible ownership and loan modes (in, ref, out), bounded loop and resource contracts with selective invariant lifting (open (...) lifts), dependent Vec<T, n> and Fin<n> mathematics with first-class proof { calc { ... } } blocks, and hygienic elaboration to Rocq/Gallina (rocq c / rocqchk) and Clight/CompCert.

          Architecture & Ergonomics
          
          
          Four pillars of verification-aware authoring
          
          
          
            Every construct in Vela is designed so that systems programmers can read ownership,
            mutation, and resource bounds directly from source, while proof engineers elaborate the
            exact same declarations to kernel-checked Rocq propositions.
          
          
        
          

        
          
          
          
            
          
              Pillar 01 · Dependent Mathematics
              
          Length-indexed Vec<T, n>, Fin<n> & calc Proofs
          
            
          
            
          
              Dependent functions quantify over erased ghost Nat n indices and carry
              first-class ensures contracts and proof { calc { ... } }
              obligations. Out-of-bounds indices and mismatched vector lengths are rejected before
              emission.
            
          
            
          public definition Vec<T, Succ(n)> KeepLength<T, ghost Nat n>(
    T head, Vec<T, n> tail)
    ensures result == Prepend(head, tail)
    => Prepend(head, tail);

public lemma PlusZeroRight(Nat n)
    ensures n + 0 == n
    proof {
        calc { assert n + 0 == n; }
        assert n + 0 == n;
    }
          
            
          
              
              
            
          
          
          

          
          
            
          
              Pillar 02 · Allocation-Free Formatting
              
          Multi-Quote Raw Strings & Checked Format.Write
          
            
          
            
          
              Vela forbids hidden heap allocation in formatting. Multi-quote raw string literals
              ("""...""") strip common indentation at compile time, and
              Format.Write(ref builder, $"...") writes into a fixed-capacity
              TextBuilder<capacity> over an explicit ref loan.
            
          
            
          public const String Banner = """
    Vela raw string:
    "quotes" stay unescaped
    """;

public Nat FormatLine(Nat count) {
    var TextBuilder<32> builder = TextBuilder.Empty<32>();
    let _ = Format.Write(ref builder, $"items={count}; ok={true}");
    return ByteLength(builder);
}
          
            
          
              
            
          
          
          

          
          
            
          
              Pillar 03 · Familiar Systems Surface
              
          Nominal Records, Total Properties, Updates & Pattern Guards
          
            
          
            
          
              Author data models with nominal record declarations, total read-only
              expression properties (public Nat Remaining => ...;), functional
              with { ... } updates, declaration-order labeled patterns, and
              let ... else / if (x is ...) guards.
            
          
            
          public record Counter(Nat Value, Nat Limit) {
    public Nat Remaining => this.Limit - this.Value;
    public bool Full => this.Value >= this.Limit;
}

public Counter Advance(Counter counter, Nat step) =>
    if (counter.Full) counter with { Limit = counter.Limit + step }
    else counter with { Value = counter.Value + step };
          
            
          
              
              
            
          
          
          

          
          
            
          
              Pillar 04 · Pure Core & Authoring Discipline
              
          Required-Static Constants, Total Arithmetic & LSP Inspection
          
            
          
            
          
              Pure Nat and bool modules compile directly to Gallina
              definitions with required-static const evaluation, canonical formatting,
              advisory lints (VELA100–VELA105), explicit
              let previews, and full LSP hover, definition, references, and inlay hints.
            
          
            
          /// Scale a runtime value by a compile-time factor.
public Nat Scale(const Nat factor, Nat value) {
    const Nat multiplier = factor * 2;
    let scaled = multiplier * value;
    return scaled;
}
          
            
          
              
              
              
            
          
          
          
        
          
      
          
    
          

    
          
      
          
        
          
          
          Language Tour
          
          
          Ownership, loans, contracts, and selective invariant lifting
          
          
          
            Vela separates immutable value passing from shared borrows (in),
            initialized exclusive borrows (ref), and uninitialized output borrows
            (out), while keeping struct and record invariants modular.
          
          
        
          

        
          
          
          
            
          1. Call-Site-Visible Loan Modes
          
            
          
              Every ordinary loan argument repeats its mode at the call site. Inference never
              silently inserts in, ref, out, or
              move. A loan ends at its last use on each control-flow branch.
            
          
            
          module Tour.Loans;

public record Window(Nat Start, Nat Count)
    invariant Bounded: Start + Count <= 4096
{
    public Nat End => this.Start + this.Count;
}

public Nat Measure(Window w) => w.End - w.Start;
          
          
          

          
          
            
          2. Selective Invariant Lifting (open (...) lifts)
          
            
          
              Instead of monolithic class invariants that break on every field mutation,
              open (ref this) lifts A, B { ... } opens only the named invariant
              conjuncts and requires them to be re-established before block exit.
            
          
            
          public struct Buffer<ghost Nat capacity> {
    private usize length;
    private Slots<byte, capacity> slots;
    invariant InitializedPrefix: LivePrefix(this.slots, this.length);
    invariant VacantSuffix: VacantRange(this.slots, this.length, capacity);

    public void Push(ref this, byte item)
        requires this.length < capacity
    {
        open (ref this) lifts InitializedPrefix, VacantSuffix {
            this.slots = Slots.Write(this.slots, this.length, item);
            this.length += 1;
        }
    }
}
          
          
          

          
          
            
          3. Bounded Loops & Decreasing Measures
          
            
          
              foreach (let i in low..high) invariant P supplies its range bound and
              decreasing measure automatically; while loops carry explicit
              invariant P decreases m clauses.
            
          
            
          module Tour.Loops;

public Nat CountTo(Nat limit) {
    var Nat count = 0;
    foreach (let index in 0..limit)
        invariant count == index
    {
        count += 1;
    }
    return count;
}

              Pure Prototype
              Checked by the pure compiler, LSP server, formatter, and Gallina emitter over Nat and bool.

              Mathematical Elaborator

              Parsed as located syntax by the conflict-free Menhir grammar for syntax campaigns.

          Assurance & Verification Boundary
          
          
          From Vela source to kernel-checked Rocq and Clight
          
          
          
            Vela separates rapid interactive feedback from foundational kernel verification. Every
            obligation discharged by the domain solver is recorded as an explicit, auditable entry in
            the solver-trust ledger rather than silently elided.
          
          
        
          

        
          
          
          
            01
            Token-Only Surface Grammar
            
          Strict UTF-8 source parsed without symbol-table feedback or syntactic ambiguity.
          
          
          
          
          
            02
            Authoring, Lints & LSP
            
          Canonical formatting, VELA100–VELA105 lints, and source-bound UTF-16 navigation.
          
          
          
          
          
            03
            Pure & Dependent Elaboration
            
          Automatic source selection between pure Nat/bool translation and full CIC elaboration.
          
          
          
          
          
            04
            Rocq Kernel Replay & Ledger
            
          Independent verification via rocq c and rocqchk with explicit solver-trust auditing.
