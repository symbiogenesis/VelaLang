ARCHITECTURE & ERGONOMICS

Four pillars of verification-aware authoring

Read ownership, mutation, and bounds directly at the call site; elaborate the exact same declarations to kernel-checked Rocq propositions.

01 · Dependent Mathematics

Length-indexed Vec<T, n>, Fin<n> & calc Proofs

Quantify over erased ghost Nat indices with first-class ensures contracts and proof { calc { … } } blocks. Out-of-bounds indices fail before emission.

public definition Vec<TElement, length> Copy<TElement, ghost Nat length>(
    Vec<TElement, length> values) => values;

public lemma SameValue() ensures PreservedValue() == 42
    proof { assert PreservedValue() == 42; }
Elaborator spec ↗
02 · Allocation-Free Formatting

Dedented Raw Strings & Checked Format.Write

Multi-quote raw strings ("""…""") strip common indentation at compile time; Format.Write(ref builder, $"…") writes into fixed-capacity TextBuilder<cap> storage.

public TextBuilder<36> FormatPacket(Nat id, bool ok) {
    let TextBuilder<36> builder = EmptyBuilder();
    let TextBuilder<36> hdr = Format.Write(ref builder, $"hdr={HeaderTag()} ");
    return Format.Write(ref hdr, $"id=0x{id:x4} ok={ok}");
}

03 · Familiar Systems Surface

Records, Total Properties, with Updates & Guards

Nominal record types, read-only => properties, functional with { … } updates, labeled patterns, and let … else / if (x is …) flow guards.

public record Counter(Nat Value, Nat Limit) {
    public bool AtLimit => this.Value >= this.Limit;
}
public definition Counter Advance(Counter counter, Nat step) =>
    if (counter.AtLimit) counter else counter with { Value = counter.Value + step };

SYSTEMS & OWNERSHIP TOUR

Explicit loans, selective invariant lifting & bounded loops

Click any card below to inspect the concrete Vela surface, or follow the specification links for the full typing rules.

01 · Loan Modes

Call-Site-Visible in, ref, out & move

Example ▾

Inference never silently inserts borrows or copies. Loans terminate path-sensitively at their last use on each branch (Core Design ↗). 

public record Window(Nat Start, Nat Count)
    invariant Bounded: Start + Count <= 4096
{
    public Nat End => this.Start + this.Count;
}
02 · Modular Invariants

Selective Lifting with open (ref this) lifts

Example ▾

Mutations open only the named invariant conjuncts they touch and re-establish them at block exit, leaving unrelated invariants intact (First-Release ↗). 

public void Push(ref this, byte item) requires this.length < capacity {
    open (ref this) lifts InitializedPrefix, VacantSuffix {
        this.slots = Slots.Write(this.slots, this.length, item);
        this.length += 1;
    }
}
03 · Termination

Bounded foreach Ranges & decreases

Example ▾

Half-open low..high ranges supply automatic bounds and decreasing measures; while loops carry explicit invariant and decreases clauses (Reference ↗). 

public Nat CountTo(Nat limit) {
    var Nat count = 0;
    foreach (let index in 0..limit) invariant count == index { count += 1; }
    return count;
}
